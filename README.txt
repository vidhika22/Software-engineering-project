# CarePoint Hospital Appointment System

Frontend-only college Software Engineering project built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract `hospital-appointment-system.zip`.
2. Open the extracted `hospital-appointment-system` folder in VS Code.
3. Install the **Live Server** extension if it is not installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Register a patient account, log in, and book an appointment.

## Admin demo login
- Email: `admin@carepoint.com`
- Password: `admin123`

## Features
- Home, registration, login, patient dashboard and appointment booking.
- Doctor directory, admin dashboard and appointment management.
- About Us and Contact Us pages.
- Browser `localStorage` is used to simulate data storage.

## Important
This is a frontend demonstration only. Authentication and data stored in localStorage are not secure and must not be used for real patient information. Contact form submissions are demonstrated locally and are not sent to a hospital.
